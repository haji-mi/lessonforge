# 架构基线（Architecture Baseline）——最终版

本文件整合 v2 → v2.1 → v2.2 → v2.3 四轮评审结论，是项目开发的**唯一权威架构参考**。早期提案与本文件冲突处，以本文件为准。

路线修订记录（相对早期提案的偏离及理由）见 §13。

## 1. 产品约束（已确认）

- 运行环境：Chrome/Edge，本地 `localhost` 纯前端 SPA，零后端。（本机已验证 Chrome 存在；Edge 为**目标环境验收项**，可延期、不可跳过，P6 交付前完成。）
- 三篇真实课程笔记由用户提供，用于 P2/P3 校准与 P6 验收；未提供前使用**明确标注的合成样本**。
- 豆包爱学以**纯文本提示词**交付（预览、编辑、复制、粘贴）。
- 自动识别课程/章节/课时；程序不含任何硬编码的课程结构。
- 本地优先；源文件只读；原始 Markdown 与生成提示词分开保存。
- 默认零第三方上传（生产构建 CSP + 测试断言）；用户编辑永不被静默覆盖。

## 2. 分层与模块边界（D=确定性，R=规则推断）

```
边界层(IO):  import / persist / export          —— 唯一触碰浏览器 IO 的层
不可变层:    custody（原始字节保管）             —— 进入后永不修改
派生层(纯函数): parse → structure → classify → compile
用户主权层:  审阅编辑 overlay                    —— 人工产物优先级最高
```

| 模块      | 职责                                          | 级别                                             |
| --------- | --------------------------------------------- | ------------------------------------------------ |
| import    | 目录/拖拽/ZIP 采集、路径规范化、类型分拣      | D                                                |
| zip       | Blob 随机访问扫描、名称四类别解码、守卫式解压 | D（模式选定后）+ R（无标志默认模式，确认制兜底） |
| custody   | 原始字节、SHA-256、解码记录、EOL/BOM 元数据   | D                                                |
| parse     | Obsidian 方言解析、全源平铺、诊断             | D                                                |
| structure | 课程/章节/课时推断（证据+确认制）             | R                                                |
| classify  | 课时类型（特征+分数+证据，可人工覆盖）        | R                                                |
| compile   | 提示词编译（A/B/C 分级、溯源、护栏）          | D（给定输入与配置输出唯一，无随机性/无 LLM）     |
| persist   | IndexedDB(Dexie)、状态机、冲突、备份          | D                                                |
| export    | 剪贴板 / Markdown / 项目 JSON / 批量 ZIP      | D                                                |

## 3. 保真不变量（全部有自动化测试）

**B 系列（字节/解码层）**

- **B1 字节保真**：项目 JSON 备份中的源文件字节与导入时**逐字节相等**；与解码/重编码完全无关（备份导出即存储字节本身）。
- **B2 解码分段映射**：解码文本一律由平台非 fatal 解码器产生（WHATWG 语义）。按 WHATWG 规则的校验器把字节流切成互不重叠分段 `{byteRange, charRange, valid}`；**核心断言：全部分段期望输出的拼接 === 平台解码文本（字符串全等）**。原文合法 U+FFFD（EF BF BD）属"有效分段"，解码器插入的属"无效分段"——结构性区分，不靠计数推断。GBK 视图不承诺文本可重编码回字节（平台 TextEncoder 仅 UTF-8），其保证为"字节无损 + 有损点逐条列明"。
- **B3 写隔离**：parse/compile/overlay 写入独立记录；SourceFileRevision 创建后不可变。
- **B4 故障隔离**：单文件任何环节失败 → 该文件标 error + 诊断码，批次其余照常。

**P 系列（解析层）**

- **P1 全源平铺**：语义叶区间 ∪ 语法 token 区间 ∪ 空白 token 区间 = 整个 T 空间（解码文本，BOM 已剥离），两两不交——每个字符必然属于三者之一。**无"白名单豁免"**；语法标记绝不归入空白类。出现无法分类的跨度 = 解析器 bug，测试失败。
- **P2 raw 精确（I-0a）**：本项目**自建节点**（wikiLink/wikiEmbed/highlight/math 等）必须满足 `node.raw === text.slice(start.offset, end.offset)`，零例外。
- **P3 value 规则（I-0b）**：标准 mdast 语义节点的 `value` 按类别枚举规则断言（text：切片经枚举的转义/实体还原后相等；code：raw 含围栏、value 为内容；math：raw 含定界符、latex 为去定界符内容）。
- **平铺实现路线**：优先由 mdast 位置残差推导（mdast position 是构造包含式的：容器节点 span 覆盖其标记，直接 span = 节点 span 减子节点 span），micromark 事件流为备选。**验收门禁是平铺不变量本身，不是具体机制**。

**T 系列（编译层）**

- **T1 溯源强制**：每条 A 级内容段必须携带可解析到当前模型 span 的 trace；编译期校验，违反即硬错误（该课时 compileError，不静默）。
- **T2 C 禁用默认**：默认配置下产物中 C 级（新增知识）段数 = 0。
- **T3 C 人工批准**：如启用 C 生成（每课时显式开关），未经逐条人工批准的 C 内容不进入导出文本。

**K 系列（完整性）**

- **K1 MKU 三态**：每个最小知识单元处于 已纳入 / 已显式排除(必填理由) / 未纳入(黄色警示) 三态之一；未纳入清单只列第三态。
- **K2 试验期门禁**：三篇真实笔记完成 MKU 校准（核心层单元边界一致率 100%、tier 归属一致率 ≥90%、校准后连续 10 课时无误报遗漏）并经用户批准前，完整性是**报告指标非阻断门禁**；审批仅要求"已查看覆盖情况"确认。

**U 系列（用户编辑）**

- **U1 不可静默覆盖**：任何自动流程（重编译/规则升级）不得静默覆盖用户编辑；冲突默认"保留我的版本"。
- **U2 可恢复**：PromptDraft 永不删除（superseded 保留）；UserOverlay 为追加式操作日志；JSON 备份含全历史。任何操作序列后，"用户最后看到的文本"可精确重建。**无自动编辑迁移**；人工辅助迁移（对比视图逐环节勾选）。

## 4. ZIP 导入规范

### 4.1 名称解码四类别（互斥）

1. **标志置位 + 严格 UTF-8 通过** → UTF-8（可靠）。
2. **标志置位 + 严格 UTF-8 失败 → `FLAG_UTF8_INVALID`**：保留原始名称字节；占位显示 `⟨名称损坏·N字节⟩` + 候选渲染（GBK/latin1，标注"仅为候选"）；用户显式选择；**不进入聚合判定、不自动降级**。
3. **extra 0x7075 + NameCRC32 校验通过** → 采用其 UTF-8 名；CRC 不符 → 忽略字段 + 诊断 + 归入类别 4。
4. **无标志** → 聚合判定 + 双候选 + 确认制：
   - 非 ASCII 组内严格 UTF-8 全部通过 → 组默认 UTF-8；任一失败 → 组默认 GBK（组内 GBK 再失败条目单试 UTF-8，成功则标"疑似混合来源"双候选）。
   - **小样本弱化**：非 ASCII 条目 ≤2 时"全过→UTF-8"证据不足，强制双候选人工裁决。
   - 双解码均合法且结果不同的条目一律在确认页展示双候选（默认显示组模式结果），可逐条改或整组切换；选择记入 ImportBatch。
   - 合理性得分（常用 CJK 区占比、常见文件名成分匹配）只用于排序提示，**不做最终裁决**。
   - 系统承诺：**不静默错误**——凡无显式信号支撑的判定必然可见、可改、留痕。

### 4.2 内存与安全模型

- **输入**：ZIP 以 File/Blob **随机访问**（不整档读入）：读尾部 ~66KB 定位 EOCD → 切读中央目录（确认页只需这两步）→ 逐条目分片读取。输入侧常驻内存 = O(分片 + 中央目录)。档案大小上限 500MB 为**策略参数**，非安全机制。
- **瞬态模型（P1b spike 已实测，docs/spike-p1.md）**：fflate 同步 Inflate 每次 push() 发射该次全部输出，`maxChunk ≈ 分片 × 膨胀比(≤1032:1)`；峰值（heap+external）≈ **5 × maxChunk**（内部缓冲倍增+拷贝）；峰值与炸弹总膨胀量**无关**。默认分片 **4KB** ⇒ 峰值恒 ≈20MB。
- **输出预算**：单条目 50MB、整档累计 300MB；检查位置在 `ondata` 回调（实际产出计数）；超限即停止喂入并丢弃引用 + `ZIP_BUDGET_EXCEEDED`（实测中止延迟 <1ms）。**spike 分支 A 判定通过**（B/C 分支保留为降级路径定义）。
- **spike 三分支（P1 验收）**：
  - A：实测峰值 ≤ 模型预测 + 5MB（说谎炸弹峰值 ≤ 预算 + 瞬态上限）→ 首选路径启用，数字入档；
  - B：部分证明 → 仅启用被证明路径；
  - C：无法证明 → **拒收式保守策略**：仅导入 Stored（方法 0）条目，DEFLATE 条目拒收 + 诊断"请改用目录导入"。**任何情况下不得自动切换到防护更弱的方案**（v2.2 的 Unzip 降级方案已删除）。
- **完整性**：解压后 CRC-32 对拍中央目录（`ZIP_CRC_MISMATCH`）；实际产出 ≠ 声明尺寸（`ZIP_SIZE_MISMATCH`）；本地头与中央目录矛盾 → 拒收；bit 3（data descriptor）时本地头零值属正常，**校验一律以中央目录为基准，数据起点取本地头自身名称/额外字段长度**。
- **路径安全**：规范化后拒绝绝对路径/盘符/UNC/`..` 段/NUL/控制字符/名称 >512 字节；虚拟根约束；规范化重名 → 诊断 + 后缀去重。
- **资源上限**：条目数 ≤10000；zip64 → 明确"暂不支持"（宁拒不错）；嵌套 ZIP 不自动展开。
- **目录导入（webkitdirectory）为主路径兼兜底**：浏览器直接给出 UTF-8 名称，无编码歧义。

## 6. 嵌入四规则

1. **路径解析**（确定性短路）：①相对当前文件目录 ②相对导入根 ③全局唯一 basename；③不唯一 → 诊断+候选+占位。
2. **重复嵌入**：每处引用独立展开；解析缓存；"来自嵌入"徽标；溯源指向被嵌入文件（跨文件 trace）。
3. **循环引用**：展开链 visited 集合，命中截断占位 + 诊断；全局深度上限 5。
4. **缺失目标**：占位 + 诊断（含原始引用文本），绝不生成内容。

## 7. 结构推断与课型识别

- **结构（R）**：信号 = 路径分段、名称模式（第X章/讲/课时/Lesson N/^\d+-，可配置默认）、frontmatter、标题层级分布。规则：课程=导入根（或单一含 ≥3 md 的子目录）；章节=含 ≥2 课时的目录或名称命中模式；课时=单个 md（拆分/合并为用户显式操作，v1 不自动）。每条推断附证据；**确认界面阻断**；人工调整持久化（source=manual，重导入按 normPath 保留）。
- **课型（R）**：特征 = 公式块密度、推导信号（证明/推导/⇒/∴/即得 + 编号步骤链）、例题信号（例N/【例/解：）、概念信号（定义/是指/称为）、练习信号。加权打分 → 类型+分数+证据；top1-top2 分差 <0.15 → 阻断询问；人工覆盖随时可用并记录。置信度是规则得分，不伪装统计概率。

## 8. 提示词编译器

- **A 原始知识**：强制 trace（T1）；只允许句式变换；公式/代码逐字（B 系列保证）。
- **B 教学组织**：确定性规则 + trace = 规则 ID + 触发依据；可解释。
- **C 新增知识**：默认禁止（T2）；显式开关 + 逐条人工批准才可导出（T3）。
- **三类策略**（环节池 + 内容可用性驱动，非固定模板）：概念课（引入→定义→属性→正例→反例(无则省)→检测→小结）；推导课（前置→命题→分步(每步预测设问，**选项只取原文后续真实步骤**)→关键点→变量表(有则)→数值验证(有则)）；例题课（题目→先试→分步揭示(每步设问)→易错(有则)→同类练习(仅原文已有，无则"练习不足"注记)）。通用兜底：讲解→小结。
- **降级**：类型不明→兜底+询问；环节内容不足→省略+"内容不足：X（原文未提供）"；结构异常→"原文转写模式"（明确标注）；异常→单课时隔离（B4）。
- **护栏**：环节间 span 重叠 >60% 去重+警告；相邻环节句级相似度告警；**未纳入清单**（可拖入补入→A 段+trace+overlay 保护）；长度软预算（默认 2000 字）警告。
- **脚手架**：固定部分（角色/课题/目标/环节骨架/输出要求）由 `promptSchemaVersion` 管理；可配置（学段学科/互动密度/环节开关/风格/长度预算）。
- **诚实边界**：溯源+完整性保证下限；教学质量只能人工判定（P6 清单）。

## 9. 持久化与冲突

- **存储**：IndexedDB + Dexie（fake-indexeddb 用于测试）；JSON 为备份/迁移格式。
- **实体**：Project / ImportBatch / SourceFileRevision（不可变，含字节）/ PathIndex（路径→修订版指针）/ ParsedDoc / StructureNode / Lesson / PromptDraft / UserOverlay / Diagnostic。
- **版本**：APP_MODEL_VERSION（存储 schema）/ PARSER_VERSION / COMPILER_VERSION / PROMPT_SCHEMA_VERSION 独立演进；未知未来版本 → 只读安全模式。
- **课时状态机**：discovered→parsed→structured→typed→compiled→edited→approved→exported（可回 edited）。派生标志：staleSource / staleCompiler / hasEdits → UI 状态：最新/有修改/需重新编译/**冲突**。
- **六场景**：刷新恢复（全量落库+快照深比较测试）；重复导入（normPath+contentHash：相同幂等、不同新增修订版+staleSource，不自动重编译不动 overlay）；源变化（同前）；编译器升级（显式重编译+差异预览）；已编辑再编译（冲突→默认保留我的版本/对比/人工迁移）；删除（两步确认+先备份导出）。

## 10. 安全

- 生产构建 CSP（仅 self + blob:/data: 资源），开发环境豁免；E2E 断言非 localhost 请求数 = 0。
- 第一版不渲染行内 HTML（⚠ 级，源码显示）；KaTeX `trust:false`；无 dangerouslySetInnerHTML（KaTeX 输出除外）。
- 源文件零写入（应用对导入文件只读）。
