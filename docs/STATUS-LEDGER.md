## 工程纪律

1. `npm run check` 退出码 0 才允许提交（不用管道 tail 掩盖退出码）。
2. 架构唯一权威：`docs/ARCHITECTURE-BASELINE.md`（不变量 B/P/T/K/U 系列）；
   发现基线与实践矛盾时，改基线并记录原因。
3. 原始笔记只读；默认零上传（CSP+断言）；用户编辑永不静默覆盖；
   测试未执行/未通过必须如实标记；不得伪造覆盖率或用户样本。
4. 每个工作包一个提交，信息写清楚做了什么+测试状态。
